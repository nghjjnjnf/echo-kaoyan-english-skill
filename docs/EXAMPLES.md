# 使用示例

## 阅读理解

```text
讲解 2023 年英一阅读 Text 3 第 32 题。完整展示题干和选项及中文翻译，先分析错误选项，再分析正确答案。
```

回答会依次给出题型与陷阱、必要原文、定位句和辅助句标记、中文翻译、完整题目、干扰项分析、正确答案证据链和复盘。

一次请求可解析 1 至 5 道题：

```text
讲解 2023 年英一阅读 Text 3 的五道题，保持每一题与单题解析相同的深度。
```

## 完形填空

```text
讲解 2021 年英一完形第 8 空。原句不要使用省略号，四个选项横向排列。
```

分析重点包括空格句法位置、固定搭配、上下文语义、篇章逻辑和干扰项陷阱。

## 翻译评分

英语一：

```text
这是我对 2025 年英一第 46 句的翻译：……
请按 2 分制逐意群评分，说明每处扣分，并在我的表达基础上修改。
```

英语二：

```text
这是我对 2024 年英二翻译全文的答案：……
请按 15 分制评分，列出意群得分、错译漏译和修改建议。
```

## 作文批改

```text
请按 2024 年英一大作文 20 分制批改下面的作文：……
```

最好同时提供原题。若没有原题，skill 会先对语言与结构评分，并明确说明任务完成度只能暂评。

范文模式：

```text
给出 2024 年英二大作文的扎实版和高级版范文，并提炼段落结构、主题词汇和可复用句型。
```

## 模拟训练

```text
围绕人工智能与就业生成一篇考研英语一难度的模拟阅读，出 5 道四选一题。先隐藏答案，等我提交后再批改。
```

从外部来源改编：

```text
从 VOA Learning English 抓取一篇不太难的文章，改编成英二阅读模拟题。先只给原文和题目，不要给答案。
```

作答后记录：

```text
我的答案是 1B 2C 3A 4D 5C。请给出解析，并把这次练习保存到本地记录。
```

若已放入词汇表：

```text
使用我的考研词表控制难度，替换明显超纲词，并列出被替换的词。
```
